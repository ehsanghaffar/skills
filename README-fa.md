# skills برای مهندسان ایرانی

مجموعه‌ای از مهارت‌های عامل (agent skills) که به طور خاص برای توسعه‌دهندگان، کسب‌وکارها و کاربران ایرانی طراحی شده‌اند.

---

## مهارت‌های مرتبط با ایران

### 1. دیجی‌کالا (Digikala) 🛒
**یکپارچه‌سازی با API باز مارکت‌پلیس دیجی‌کالا**

مارکت‌پلیس دیجی‌کالا بزرگ‌ترین پلتفرم تجارت الکترونیک ایران است. این مهارت دسترسی کامل به **۲۷۴ نقطه پایانی (endpoint)** API باز فروشندگان را فراهم می‌کند.

#### قابلیت‌ها:
- **مدیریت توکن**: توکن دستی از طریق متغیر محیطی `DIGIKALA_ACCESS_TOKEN` یا فایل `~/.digikala/token`
- **مدیریت محصول**: جستجو، اعتبارسنجی دسته‌بندی، ایجاد پیش‌نویس، آپلود تصاویر، بررسی کیفیت با هوش مصنوعی، ذخیره و تخصیص به فروشنده
- **ناوبری دسته‌بندی**: درخت دسته‌بندی‌ها، جستجوی کلمات کلیدی، اعتبارسنجی برای ایجاد محصول
- **مدیریت تصاویر**: آپلود به فضای موقت، بررسی کیفیت با AI
- **سفارشات، ارسال، مالی، پشتیبانی مشتری**: نقاط پایانی مستند شده در مراجع

#### اسکریپت‌های آماده:
```bash
# تنظیم توکن (یک بار)
export DIGIKALA_ACCESS_TOKEN="توکن_دسترسی_شما"
# یا: echo "توکن_دسترسی_شما" > ~/.digikala/token && chmod 600 ~/.digikala/token

# محصولات
bash scripts/product-create.sh search "آیفون ۱۵"
bash scripts/product-create.sh validate-category 6351
bash scripts/product-create.sh save-title 123 "گوشی موبایل اپل آیفون ۱۵"

# دسته‌بندی‌ها
bash scripts/category.sh tree
bash scripts/category.sh search "موبایل"

# تصاویر
bash scripts/image.sh upload-product ./product.jpg
bash scripts/image.sh ai-check "img_abc123" true
```

#### نکات مهم:
- محتوای فارسی/پارسی در بسیاری از فیلدها (عنوان، توضیحات، نام دسته‌بندی)
- ثبت‌نام کلاینت الزامی است (تماس: `Marketplace-API@digikala.com`)
- هر نقطه پایانی نیاز به Scope خاص دارد
- تصاویر موقت منقضی می‌شوند؛ از `use_temp_images: true` در ذخیره محصول استفاده کنید
- نرخ کمیسیون حسب دسته‌بندی متغیر است
- **توکن‌ها توسط اسکریپت‌ها ذخیره نمی‌شوند؛ از متغیر محیطی یا فایل توکن استفاده کنید**
- محیط Sandbox برای توسعه: https://github.com/salimousavi/seller_service_sandbox

### ۲. مانیتور بازارهای مالی ایران (Iran Finance Markets Monitor) 📊
**پایش، جمع‌آوری، اعتبارسنجی، مقایسه، خلاصه‌سازی و گزارش بازارهای مالی ایران**

پوشش کامل بازارهای مالی ایران شامل:

#### بازارهای پوشش‌داده:
- **ارز**: دلار/تومان، یورو، درهم امارات
- **طلا**: سکه امامی، طلای ۱۸ عیار، نیم‌سکه، ربع‌سکه، گرمی
- **ارزهای دیجیتال**: USDT/تومان، بیت‌کوین، اتریوم
- **نمادهای بورس**: شاخص کل، نمادهای برتر
- **شاخص‌ها**: Fear & Greed، TGJU، نوبیتکس، والکس، بیت‌پین

#### ویژگی‌ها:
- جمع‌آوری داده با رastreability کامل (ثبت منبع و زمان)
- عدم اختراع مقادیر گم‌شده — گزارش صریح خطای منبع
- مقایسه قیمت‌ها در چند صرافی/منبع
- گزارش بازار به زبان فارسی
- اعتبارسنجی متقابل داده‌ها

#### کاربردها:
- پایش لحظه‌ای نرخ ارز و طلا
- مقایسه قیمت ارزهای دیجیتال در صرافی‌های ایرانی
- گزارش روزانه/هفته‌ای بازار برای تصمیم‌گیری سرمایه‌گذاری
- یکپارچه‌سازی با سیستم‌های تراکنشی و حسابداری

### ۳. اجباری‌سازی فارسی در تلگرام (Telegram Persian Enforcer) 🇮🇷
**اجبار خروجی فارسی برای تمام تعاملات گروه، کانال و پیام‌های مستقیم تلگرام**

#### قابلیت‌ها:
- تشخیص خودکار زبان و تبدیل به فارسی
- اصلاح نگارش و املا (ی/ی، ک/ک، espace‌های نیم‌فاصله)
- پشتیبانی از اعداد فارسی
- اعمال بر تمام پیام‌های خروجی عامل در تلگرام
- قابل تنظیم برای گروه‌ها، کانال‌ها و پیام‌های مستقیم

#### موارد استفاده:
- ربات‌های تلگرام فارسی‌زبان
- کانال‌های خبری و اطلاع‌رسانی ایرانی
- گروه‌های پشتیبانی مشتری به زبان فارسی
- اتوماسیون محتوای شبکه‌های اجتماعی فارسی

## دستورالعمل‌های کلیدی برای کاربران ایرانی

### ۱. کدگذاری کاراکترها (Encoding)
همه اسکریپت‌ها و فایل‌ها با کدگذاری **UTF-8** ذخیره شده‌اند. اطمینان حاصل کنید که ترمینال و ویرایشگر شما روی UTF-8 تنظیم شده است.

### ۲. اعداد فارسی
مهارت‌های مالی به طور خودکار اعداد انگلیسی را به فارسی تبدیل می‌کنند:
```
۱۲۳۴۵۶۷۸۹۰ ← 1234567890
```

### ۳. تقویم شمسی
برای کار با تاریخ‌های شمسی، از کتابخانه‌های標准 مثل `jdatetime` (پایتون) یا `moment-jalaali` (جاوااسکریپت) استفاده کنید.

### ۴. منطقه زمانی
تمام مهارت‌ها به طور پیش‌فرض از **Asia/Tehran** (UTC+3:30) استفاده می‌کنند.

### ۵. متغیرهای محیطی پیشنهادی
```bash
# در ~/.bashrc یا ~/.zshrc اضافه کنید
export TZ="Asia/Tehran"
export LANG="fa_IR.UTF-8"
export LC_ALL="fa_IR.UTF-8"
```

## مشارکت و توسعه

### افزودن مهارت ایرانی جدید
1. دایرکتوری با نام `kebab-case` در `skills/` بسازید
2. فایل `SKILL.md` با فرمت استاندارد بنویسید
3. اسکریپت‌ها در `scripts/`، مستندات در `references/`
4. توضیحات (description) شامل عبارات محرک فارسی باشد
5. این فایل README-fa.md را به‌روزرسانی کنید

### اصول طراحی برای بازار ایران
- **پشتیبانی کامل از RTL و فارسی**
- **استفاده از تقویم شمسی** در گزارش‌ها
- **یکپارچه‌سازی با سرویس‌های ایرانی** (بانک‌ها، درگاه‌ها، پست، پلتفرم‌های داخلی)
- **رعایت مقررات و قوانین ایران** (حریم خصوصی، داده‌های مالی)
- **مستندات دو زبانه** (فارسی/انگلیسی)
