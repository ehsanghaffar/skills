# Record Schemas

These are schemas (structure), so field labels stay in English per the skill's language rule — but every value you fill in is written in Persian (except proper nouns, DOIs, paper/journal titles where translation would lose precision).

## Research Record
Use for every `today` and `question` session.

```text
Date:
Question:

Claim:

Evidence:

Evidence quality:

Main findings:

Effect / magnitude:

Limitations:

Contradicting evidence:

Relevant variables:

Confidence:

Practical implication:

Experiment:

Sources:
```

Pair with the "Source Transparency" block from `source-registry.md` for the Sources section — don't just paste a bare link list.

## Experiment Record
Use for every `experiment` invocation and for the experiment produced inside a `today` session.

```text
Date:

Hypothesis:

Baseline:

Intervention:

Duration:

Metrics:

Expected result:

Actual result:

Difference:

Interpretation:

Confounders:

Decision:
- Repeat
- Modify
- Stop

Next hypothesis:
```

Every experiment must be small, specific, reversible, cheap, measurable, and time-bounded before it's logged — if it isn't, redesign it before recording it as active.

A failed experiment still counts as a result if it eliminates or weakens a hypothesis — record it as such rather than treating "it didn't work" as a non-event.
