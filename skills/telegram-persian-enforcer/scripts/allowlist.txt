# هر خط یک عبارت که مجاز است در متن فارسی به همان صورت لاتین باقی بماند
# (حساس به بزرگی/کوچکی حروف نیست). این‌ها موارد جاافتاده‌ای‌اند که معمولاً
# حتی در نوشتار فنی فارسی ترجمه/نویسه‌گردانی نمی‌شوند.
#
# ⚠️ این فایل یک «درگاه تصویب» نیست. هر افزودنی ممکن است در آینده
# یک کلمه‌ی لاتین غیرضروری را از پرچم‌گذاری بگذراند. برای هر افزودنی
# حتماً پاسخ به این سؤال را برای خودتان ثبت کنید:
#   «آیا این اصطلاح واقعاً باید به همین صورت لاتین بماند، یا می‌توانم
#    نویسه‌گردانی فارسی یا توضیح فارسی بدهم؟»
# اگر پاسخ «بله، واقعاً نیاز به لاتین دارد» است، دلیل آن را در کنار
# خط بنویسید (مثلاً: «نام رسمی محصول است»).
#
# برای پیشنهادهای جدید از `python check_persian.py --pending` استفاده کنید
# تا موارد در scripts/pending.txt (پیش‌نویس، منتظر تأیید) قرار گیرند،
# نه مستقیماً اینجا. سپس پس از بررسی، موارد تأییدشده را اینجا بیاورید.
#
# برای بررسی نهایی پیش از ارسال، حتماً از `--strict` استفاده کنید تا
# این فهرست نادیده گردد و هر چیز لاتینی پرچم شود.

# --- موارد تأییدشده ---
