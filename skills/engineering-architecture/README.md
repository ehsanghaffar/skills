# Engineering Architecture

Persistent engineering and architectural principles for every task.

## Usage

Invoke when you need to:
- Make changes to a codebase
- Design a new feature
- Perform a code review

## Principles

14 principles covering: think beyond the task, audit before changing, quality attributes, respect boundaries, constraints over prescriptions, minimize complexity, verify with evidence, agents as reviewers, facts vs preferences, security, preserve behavior, trade-offs, smallest proof, definition of done.
