# Engineering Architecture — Skills Directory

This skill provides persistent engineering and architectural principles. It is principles-only — no scripts required.

## Usage

The skill is invoked automatically when you:
- Make changes to a codebase
- Design a new feature
- Perform a code review

## Principles

14 principles are defined in SKILL.md covering:
- Think beyond the task
- Audit before changing
- Requirements include quality attributes
- Respect boundaries
- Prefer constraints over prescriptions
- Minimize architectural complexity
- Verify architecture with evidence
- Treat agents as reviewers
- Separate facts from preferences
- Security as architectural concern
- Preserve existing behavior
- Make trade-offs explicit
- Use the smallest proof
- Definition of done

## Scripts

No scripts — this is a memory/principles skill. The SKILL.md contains all 14 principles.
