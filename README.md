# Skills For Engineers

A collection of agent skills I actually use in my day-to-day work.

Not vibe coding. Not “let the AI figure everything out.”

Keep the skills small. Keep them composable. Make them easy to understand, modify, and replace.

No need to lock yourself into one methodology. Use whatever works, combine things differently, and adapt them to your own workflow.

They’re built around practical software engineering principles and years of experience—not around a single “correct” way of working with agents.

Take them, break them, tweak them, and make them yours.
